# FLOWDO

**向内走　向外长**

FLOWDO 是一本在电脑浏览器里使用的电子手账。用愿望照片提醒自己想成为什么样的人，用每周行动推进计划，再把经历写下来，慢慢养成自己的信念。

## 从哪里开始

| 你想做什么 | 入口 |
| --- | --- |
| 打开最新版手账 | 在电脑浏览器打开 [手账入口](design-demos/notebook-2026-11-04/index.html)，或直接打开同目录的 `dir-1.html` |
| 管理冥想音频 | 运行下方的本地音频后台，再从它的地址打开手账 |
| 开发独立的 Cloudflare 应用 | 进入 [app/](app/) 并参照 [应用 README](app/README.md) |
| 查阅页面设计与需求 | [FLOWDO 网页设计需求](docs/FLOWDO-网页设计需求-2026-11-09.md) |

## 手账里有什么

从封面翻开，依次是 **FLOWDO、我的愿望、每周计划、10周计划、此刻的我、信念养成、我的冥想**，最后是封底。

- **愿望与行动**：首页轮播愿望照片。愿望页管理图片与肯定语。每周行动支持编辑和按次数打卡；十周计划可以新建、预览月历并打开详情。
- **觉察与信念**：「此刻的我」可按觉知、全观、调衡记录，并保存本地。「信念养成」可以分别记录已经笃定的信念、正在改变的信念及其对应经历。
- **冥想跟练**：按助眠、能量、关系、减压、专注浏览音频，可添加到「静心时光」。播放器支持播放、暂停、关闭和拖动进度，播放时唱片转动。内置「钵体冥想」示例钵音。

直接用浏览器打开手账可以体验界面和示例音频。计划、觉察、信念和静心列表使用当前浏览器本地存储。愿望照片和配文尚未接上长期保存。语音转写依赖浏览器支持及麦克风权限。

## 本地冥想音频后台

建议使用 Node.js 24。后台使用 Node 自带的 SQLite，默认只监听当前电脑的 `127.0.0.1`。

```sh
node design-demos/notebook-2026-11-04/meditation-admin/server.mjs
```

1. 打开 `http://127.0.0.1:8765/admin`，使用启动终端中显示的本次管理密码。
2. 上传音频，选择分类并发布。
3. 打开 `http://127.0.0.1:8765/dir-1.html#meditation` 查看已发布的音频。管理页和手账使用同一个本地地址。

macOS 也可双击该目录下的 `启动冥想后台.command`。音频和后台数据保存在后台目录的 `.local/`。用文件方式打开的手账与通过本地服务器打开的手账会使用不同的浏览器存储空间，已有记录不会自动互通。

## 独立应用开发

`app/` 是另一个本机开发版本，技术栈为 React、Vite、Hono 和 Cloudflare Workers，包含账号、私人图片、愿望板、周计划、书写记录与 ZIP 导出。它与手账原型有各自的界面和数据。

```sh
cd app
npm ci
npm run setup:local
npm run db:local
npm run dev
```

默认地址为 `http://127.0.0.1:5173/`。环境配置、开发命令和云资源待办详见 [应用 README](app/README.md) 与 [资源待办](app/RESOURCE_TODO.md)。

当前的音频管理是本地功能。AI 复盘、联网会员、正式生产后台及公开部署属于后续工作。
